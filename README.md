# VisualSport

VisualSport — безкоштовний спортивний додаток для підлітків. Він допомагає обирати вправи та займатися спортом. Дані зберігаються локально у браузері.

**[Відкрити опублікований VisualSport](https://veronikaslahova89-cmyk.github.io/TeenFit-AI/)**

## Основні функції

- Створення тренувань за рівнем підготовки, ціллю та доступним часом: через OpenRouter або вбудований режим без API-ключа.
- Перегляд вправ із таймером і звуковими сигналами.
- Збереження обраних вправ і швидкий доступ до них.
- План тренувань на 7 днів із вправами та днями відпочинку.
- Відгук після тренування та адаптація наступних тренувань на основі історії.
- Історія тренувань, серія активності, досягнення й тижневі челенджі.
- Українська й англійська мови інтерфейсу та тренувань.
- Поширення результату, локальні нагадування та встановлення як PWA з підтримкою офлайн-режиму.

Потрібен Node.js 20.19+.

## AI-режим

1. Відкрий **AI Налаштування**.
2. Встав ключ OpenRouter (`sk-or-v1-...`).
3. Обери одну з безкоштовних моделей.

Ключ зберігається лише в `localStorage` браузера і надсилається тільки до OpenRouter. Без ключа або без мережі застосунок автоматично працює в mock-режимі.

## PWA та офлайн

- Манифест, іконки, service worker і precache налаштовані у `vite.config.ts`.
- Для встановлення та service worker потрібен **HTTPS** (або `localhost`).
- Android/Chrome: меню браузера → «Встановити застосунок».
- iOS Safari: «Поділитися» → «Додати на головний екран».
- В офлайні доступні оболонка, історія, челленджі та mock-тренування; AI-запити не кешуються.

### Обмеження нагадувань

Без бекенду та push-сервера нагадування працює, лише поки застосунок відкритий або встановлений і запущений. Якщо повністю закрити застосунок, система не розбудить його для сповіщення.

## Деплой

Опублікований сайт: [Відкрити VisualSport](https://veronikaslahova89-cmyk.github.io/TeenFit-AI/).

GitHub Actions автоматично збирає та публікує сайт на GitHub Pages після оновлення гілки `main`.

Для ручного деплою збери проєкт і завантаж вміст `dist/` на будь-який статичний хостинг (Netlify, Vercel, Cloudflare Pages, GitHub Pages тощо).

Для SPA потрібен fallback на `index.html`. Після деплою переконайся, що сайт відкривається через HTTPS — інакше PWA та сповіщення не працюватимуть.

## Структура

```
src/
  App.tsx                 # стан застосунку та сценарії
  components/             # UI: тренування, плани, модалки, челленджі
  challenges.ts           # тижневі челленджі та статистика
  i18n.ts                 # словники UK/EN, контекст мови, плюралізація
  share.ts                # текст результату + Web Share API
  sound.ts                # синтезовані звукові сигнали таймера
  openrouter.ts           # AI-запити та fallback
  mockData.ts             # локальні тренування й плани (UK/EN)
  storage.ts              # localStorage, стрік, досягнення, історія
  reminders.ts            # дозволи та локальні нагадування
  types.ts                # типи, моделі, константи
public/                   # PWA-іконки, favicon, robots.txt
```

## Дані та приватність

Усе зберігається локально:

- `teenfit_data` — стрік, історія тренувань, досягнення;
- `teenfit_settings` — ключ OpenRouter, модель, мова, звук і налаштування нагадувань;
- `teenfit_last_reminder` — дата останнього нагадування.

Немає акаунтів, синхронізації між пристроями та серверної аналітики. Дані можна очистити в налаштуваннях браузера.

## Відомі обмеження

- Немає рейтингу друзів і синхронізації — для цього потрібен бекенд.
- Шаринг текстового результату, без генерації картинки для сторіс.
- В офлайні AI замінюється mock-тренуваннями.
- Зовнішній шрифт Google Fonts в офлайні замінюється системним.
- Уже згенероване тренування не перекладається на льоту: після зміни мови почни нове тренування. Тижневий розклад оновлюється автоматично.
